# Finance MCP KZ

A local MCP server for analyzing personal Kaspi and Freedom PDF statements in KZT.

The project is developed in learning stages. Only the project skeleton exists:
PDF import, database storage, and MCP tools are not implemented yet.

## Main use cases

- Spending by category and merchant across multiple banks.
- Period comparisons that explain changes in spending.
- Recurring payments, new merchants, and the largest expenses.

The server handles parsing, deduplication, rules, and calculations.
The agent resolves ambiguity and provides recommendations.

## Project structure

- `src/finance_mcp/` - application code.
- `tests/` - automated tests without network access or a real database.
- `data/` - local personal data; excluded from Git.
- `pyproject.toml` - project metadata and quality check settings.
- `PLAN.md` - implementation stages and commit workflow.
- `LEARNING.md` - local exercises and explanations.

## Development setup and checks

Create an environment and install development tools (Python 3.12+;
`--group` requires pip 25.1+):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --group dev
```

In PowerShell, temporarily add the environment to the current terminal's path:

```powershell
$env:Path = "$PWD\.venv\Scripts;$env:Path"
```

This affects only the current terminal and does not change script execution policy.
Then run:

```powershell
pytest -q
ruff check .
ruff format .
mypy src/
```

If formatting changes code, rerun tests, linting, and type checking.
Passing these checks does not establish bank support; verified samples are required.

## Generated caches

Development tools create these local directories automatically:

- `.pytest_cache/` - pytest run metadata, including previous test failures.
- `.ruff_cache/` - cached results used to speed up Ruff checks.
- `.mypy_cache/` - cached type analysis used to speed up mypy.

These directories are excluded from Git and are not application data.
They can be removed when the tools are not running; the next run recreates them.
The README inside `.pytest_cache/` is generated by pytest.

## Personal data

Do not commit real statements, databases, `.env` files, or secrets.
PDFs are ignored by default. Test samples will be added separately after
their anonymization has been verified.
